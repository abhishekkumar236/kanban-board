Linear-lite · complete flow

From sign up to log out, in 14 screens

Every screen is 1440 × 900, the size of a desktop Figma frame. Each one is a route in your Next.js app, shown above the frame, with a line on the React skill it teaches. The SVG copies for Figma are in the figma/ folder next to this file.

Getting these into Figma

  1. 1. Open or create a Figma design file.
  2. 2. Open the figma/ folder in Finder, select all 15 SVG files and drag them onto the canvas.
  3. 3. Each file becomes its own frame, named after the screen, with editable text and shapes. Layers are grouped as Sidebar, Board, Card WEB-12 and so on.
